
# Amazon Sales Data Analysis Using MySQL

## 📌 Project Overview

This project focuses on analyzing Amazon sales data using MySQL to extract meaningful business insights. The project involves data cleaning, data standardization, exploratory data analysis (EDA), and SQL-based analysis to understand sales performance, order patterns, product categories, and customer purchasing trends.

The main objective is to transform raw sales data into structured information that can support data-driven business decisions.

## 🎯 Project Objectives

- Clean and prepare raw Amazon sales data for analysis.
- Identify duplicate records and potential data quality issues.
- Standardize inconsistent city names and other text values.
- Handle missing, blank, and inconsistent data.
- Analyze order status and fulfillment performance.
- Explore product categories, sizes, and sales channel patterns.
- Identify sales trends and product performance.
- Generate actionable business insights using SQL queries.

## 🛠️ Tools and Technologies

- **Database:** MySQL
- **Language:** SQL
- **Concepts:** Data Cleaning, Data Transformation, Exploratory Data Analysis (EDA)
- **SQL Techniques:** SELECT, WHERE, GROUP BY, ORDER BY, CASE WHEN, Aggregate Functions, Subqueries, CTEs, Joins, and Window Functions (where applicable)

The following data preparation activities were performed or investigated using SQL:

- Checked for duplicate records.
- Reviewed missing and blank values.
- Standardized inconsistent text values.
- Cleaned city names and corrected identified spelling inconsistencies.
- Used SQL string functions and conditional logic to identify data quality issues.
- Reviewed data types and column names for consistency.
- Validated cleaned data before conducting analysis.

## 📊 Exploratory Data Analysis

The analysis focuses on answering business questions such as:

1. What is the overall order and sales performance?
2. Which product categories have the highest order volume?
3. Which sizes are ordered most frequently?
4. What is the distribution of order statuses?
5. How do different fulfillment methods perform?
6. Which sales channels contribute the most orders?
7. Which cities and states have the highest order volume?
8. What are the monthly sales and order trends?
9. How do cancelled orders affect overall performance?
10. Which products or SKUs have the highest demand?
